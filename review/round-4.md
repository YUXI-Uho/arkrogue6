# Round 4 — 用户反馈的三类问题（生效对象 / 特殊效果 / 作用域）

> 输入：用户指出「部分藏品效果生效场景和对象错误（例如人偶之家：初始费用 +10 是局内初始费用，
> 不是干员部署费用）」「存在『特殊效果无法量化』模块，希望按官方伤害定义修正」「部分藏品作用域模糊」。

## 1. 排查结论

### 1.1 人偶之家本身是对的，但同族有真 bug

`056/057/058` 在数据里是 `initCost`（bucket=run），引擎不会把它加到任何干员面板上：

```
056 人偶之家 → initCost flat 10（scope=all, bucket=run）
computeOperator(玛恩纳, 选中 056) → final.cost 12（基础 12，不变）
```

真正的错在同族的两条上（都在 `tools/build_relics_official.py`）：

| 藏品 | 官方 buff | 旧行为 | 修正 |
| --- | --- | --- | --- |
| 160 钝爪-先机 | `global_buff_normal` key=`rogue_6_char_skill_add_cost`，cost=3 | 记成 `cost +3` → 所有先锋**变贵 3 费** | 新增属性 `dpOnSkill`（技能开启获得部署费用），bucket=run |
| 162 铁卫-轻行 | `deck_card_buff` cost_scale=0.25 | 已经是对的（cost -75%，cond=firstDeploy） | 保持 |

另外把「费用类不进文案补漏」写成硬规则：引擎用官方 mods 打底时，不再把文案解析出的
`cost / initCost / spCost / dpOnSkill` 补进去 —— 中文里「获得 3 点部署费用」「首次部署费用 -75%」
「初始部署费用 +10」极易被解析成同一个 `cost`，补进去就会算到干员头上。

### 1.2 作用域：官方 selector 是「八个职业全选」，文案才写真实范围

`高台干员 / 地面干员` 类藏品（113 红日冠冕、114 黑夜披肩、119 庇护、214 羽蛇翁）在官方数据里
`selector.profession = WARRIOR|SNIPER|…|PIONEER`（八职业全选），如果照搬，高台藏品会加到近战干员身上。
另一些（146 折戟-浴血、153 医者-自医）官方 buff 干脆没有 selector，文案却写了「所有【近卫】干员」。

修法：`apply_text_scope()` —— 用官方 `usage` 文案收紧作用域：

- 文案出现「所有【X】干员」→ 若当前是「全体」或「八职业全选」，收紧到该职业；
- 文案出现「地面干员 / 近战位」「高台干员 / 远程位」→ 补 `positions`；
- 敌方作用域、指定干员（assign）、分支作用域不参与收紧。

### 1.3 「特殊效果」里混进了调试串

旧版把没转换的 buff 原样塞进 special：`[next_recruit_upgrade_char_buff char_buff=rogue_6_from_relic_9]`。
现在：

- 构建脚本不再输出调试串；
- 「特殊效果」只收文案里可读的残句；
- 完全没有数值的藏品也会留一条（用官方 usage 文案），避免「选了却哪都不显示」；
- 卡片改名为「特殊效果（不改变数值）」，并加一句说明：招募 / 掉落 / 节点 / 结局条件、战术道具。

## 2. 新增：伤害估算（官方公式）

「汇总」页顶部新增伤害估算卡：

```
物理 = max(攻击×倍率 − 有效防御, 攻击×倍率×5%) × (1 + 造成伤害% + 脆弱% + 物伤易伤%)
法术 = max(攻击×倍率×(1 − 法抗/100), 攻击×倍率×5%) × (1 + 造成伤害% + 脆弱% + 法伤易伤%)
真实 = 攻击×倍率 × (1 + 造成伤害% + 脆弱% + 真伤易伤%)
有效防御 = 敌方防御 × (1 − 无视防御%)
```

配套改动：

- 新增属性 `defIgnore`（无视防御，178 残弩-新典训 50%）；
- `estimateDamage(input, mods, ctx, op)` 在 `js/engine.js`，传入 op 时按作用域过滤（指定干员的加成不会算给全队）；
- 受影响的藏品（`physTaken` / `magicTaken` / `trueTaken` / `dmgReduce` / `weak` / `defIgnore`）现在都有数值出口。

## 5. 仍未解决 / 需要确认

1. **152 断杖-波纹**：`perProfession` 的驱动是「场上术师人数」，但人数默认 0，需要用户手填或点「按编队填充」。
2. **173 剿袭之手**：秘术师 / 神射手 / 猎手的「进入攻击范围」判定是行为类，只量化了 300% 伤害与 50% 脆弱。
3. **209 猎印**：「每层探测先锋 +10 法抗」按 1 层固定计入（缺少层数输入口）。
4. **171 波纹之手** 后半句「造成伤害后 3 秒内攻击力 +20%（最高 +100%）」未量化。
5. 伤害估算目前是「单次伤害」，不含技能持续、攻击间隔、多段、暴击等；需要的话可以加成 DPS 模式。
