## 二、第一轮自审：找到 5 个问题

**① 一个「假绿灯」（最严重）**
`check_enums` 第 6 项「产物自洽」原本从 `build_db.py` 里正则解析 `TABLE_SPEC` 拿列定义。
B2 把那个字面量删掉后，解析结果变成 `{}`，于是 `for name, (pk, cols) in spec.items()` 一次都不执行 ——
**检查项什么都没查，却打印「枚举与属性注册表一致」**。这是最坏的一种失败：不是报错，是沉默。
修法：列定义改从 `schema.js` 解析，并把「产物列 == schema 列」也加进去。修完 `-v` 重新打印出 9 张表的行数才算真的在跑。

**② 提示条的件数比肉眼多**
淡化模式下，提示条写「淡化的 N 件与本队无关」，但 N 的算法没排除「已选中」的藏品 ——
而已选中的即使无关也不会淡化（否则取消不掉）。于是勾一件无关藏品后，N 不降反而不变，数字和画面打架。
修法：计数时跳过 `state.relics[r.id]`；补两条断言把「N == 实际淡化瓦片数」和「勾选后 N-1」钉住。

**③ `check_overrides` 用了 `io` 却没导入**
第一次跑就炸在 `name 'io' is not defined`。这种错在「只跑一次就交付」的流程里很容易漏 ——
因为报错的是检查脚本自己，看起来像「检查脚本坏了」而不是「数据有问题」。

**④ 第 10 项检查的启发式误报**
第一版按「字符串后 12 个字符里有没有 `"w"`」判断读/写，结果把
`os.path.join(DATA, "overrides", "relics.json")` 和 `print("wrote data/operators.json")` 都判成了「读」。
修法：只认「这一行真的在开文件」（`open(` / `load(` 出现在同一行），并且排除 `overrides`。

**⑤ `renderSummary` 的收尾大括号顶格**
`}` 落在第 0 列，是全文件唯一的顶格括号。语法上无害，但下一次用「找顶格括号」定位函数边界的人会被它坑。

## 三、第二轮自审：找到 3 个问题 + 1 处说法不实

**⑥ 编号压住名字**
紧凑瓦片 88px，名字 11px、右上角绝对定位贴 3 位编号。四个字的名字正好顶到编号上。
修法：`.relic:not(.selected) .relic-name { padding-right: 20px }`。

**⑦ `build_db.py --check` 的退出码没传出去**
`main()` 里 `return 1` 是对的，但入口写的是 `main()` 而不是 `sys.exit(main())`，
于是「产物过期」这个信号在 CI/脚本里等于不存在。
修法：改 `sys.exit(main())`，然后**真的去篡改一次 `dataHash` 验证 exit=1**，再重建恢复。

**⑧ B3 的验收标准我自己写错了**
计划里写「干净 clone 后能从零重建」，但我核对 `git ls-files raw/` 的结果是 **0 个文件** ——
`raw/` 是 53MB 官方表，在 `.gitignore` 里。所以干净 clone 连中间产物都重建不出来，
这条验收从写下那天起就不可能达成。

不粉饰：**B3 只达成一半**。能做到的是「从中间产物重建表产物」（`--skip-build`），
做不到的是「从零重建中间产物」。中间产物继续留在版本库，理由不是它们是源，
而是它们是 `raw/` → 界面的唯一可复现路径。这个结论和依赖方向一起写进了 `data/README.md`，
并用第 10 项检查守着（缓存只能是输出，不许被读回来）。

**⑨ 检查项写完不算数，得能证明它会红**
第 10 项写完后，我往 `build_operators.py` 里临时插了一行
`json.load(open(os.path.join(ROOT, "data", "operators.json")))`，确认它报错、再还原。
第一版没报（因为插错了位置，`def main()` 在那个文件里不存在），第二版才验证成功 ——
**如果没做这一步，我会以为检查有效，其实它从没跑过真正要抓的那种写法。**

## 五、为什么这轮是串行做的

原指令是「3 个 agent 同时进行，各自自审 2 次，第 4 个 agent 取优，筛两次」。
实际执行时 3 个 agent 全部返回 `429 usage exceeds frequency limit`，一个字节都没产出。
等额度恢复后由我串行完成，所以：

- 「取优」这一步**没有发生** —— 不存在三份候选，也就无从比较；
- 「自审 2 次」我按两轮做了，但**两轮都是同一个视角**，不是三个独立视角的交集。
  这比真正的三路并行弱：同一处盲区，我自己审两遍还是看不见。

上面 9 条问题是这两轮的净产出，其中 ①⑦⑧ 属于「不改就会留下假绿灯或假承诺」的那一类。
